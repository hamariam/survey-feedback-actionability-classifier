# 📝 Survey Feedback Actionability Classifier

A small demo showcasing an AI-powered text classifier that determines whether a sentence is actionable or non-actionable.

## About the Project

This project uses a fine-tuned DistilBERT model trained on a synthetic dataset of actionable and non-actionable survey feedback.

The goal is to help organizations identify suggestions and opportunities for improvement from qualitative survey responses.

## Model

The model is hosted on Hugging Face.

## Dataset

The model was trained using 100 synthetic survey feedback responses.

## Limitations

This is an experimental portfolio project. The model was trained on a small synthetic dataset and should not be considered production-ready. Predictions should be reviewed by a human.
